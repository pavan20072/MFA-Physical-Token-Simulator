01

Factor 1 — Registered Number

The user's registered number is the first identity input. In this simulator, use a valid 10-digit Indian mobile number.

02

Factor 2 — SMS OTP

A six-digit OTP is generated after the number is accepted. The browser prototype displays a demo OTP; a real system must send it through an SMS provider.

03

Factor 3 — MFA Token

The physical-token simulator produces a changing six-digit code. The token must be correct and still within its 30-second validity window.

04

Access Decision

Access is granted only after the registered number, SMS OTP and current MFA token are all verified successfully.
